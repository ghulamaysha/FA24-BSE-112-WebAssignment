Lecture 4

Semantic HTML and HTML Forms

Meaningful structure and user input

Summary

This lecture separates block-level and inline elements and shows how semantic tags make pages clearer for people, search engines and screen readers. It then builds forms and validates input in the browser with HTML5 attributes.

Topics Covered

  • Block and Inline
    • Block-level vs. inline elements
    • div and span
  • Semantic Elements
    • header, nav, main, section, article, aside, footer
    • Accessibility and SEO benefits
  • Forms and Validation
    • action, method, input types, select, textarea and button
    • required, pattern, min and max

Example Code

<form>
  <input type="text" placeholder="Name" required>
  <input type="number" min="1" max="8" placeholder="Lecture">
  <select>
    <option>HTML</option>
    <option>CSS</option>
  </select>
  <button type="submit">Submit</button>
</form>
