Lecture 8

CSS3 Features

Modern effects without images or scripts

Summary

This lecture covers the visual features introduced in CSS3: rounded corners, gradients, shadows, transforms, transitions and keyframe animations. It also introduces web fonts, custom properties, media queries and cross-browser compatibility.

Topics Covered

  • Visual Effects
    • Rounded corners, gradients, shadows and opacity
    • 2D/3D transforms
  • Motion
    • Transitions
    • Keyframe animations
  • Tooling
    • Web fonts, icon fonts and custom properties
    • Media and feature queries
    • Vendor prefixes and cross-browser compatibility

Example Code

.css3-card {
  padding: 24px;
  border-radius: 16px;
  background: linear-gradient(135deg, #134b40, #2da084, #6fcf97);
  box-shadow: 0 8px 20px rgba(31, 112, 97, 0.35);
  transition: transform 0.3s ease;
}
.css3-card:hover {
  transform: rotate(-2deg) scale(1.04);
}
.pulse {
  animation: pulse 1.6s infinite ease-in-out;
}
@keyframes pulse {
  50% { transform: scale(1.6); opacity: 0.5; }
}
