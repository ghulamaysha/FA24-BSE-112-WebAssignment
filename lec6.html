Lecture 6

The CSS Box Model and Display

Every element is a box

Summary

Every element on a page is a rectangular box. This lecture explains content, padding, border and margin, how sizing and overflow behave, and how the display property changes the way a box sits on the page.

Topics Covered

  • Box Model
    • Content, padding, border and margin
    • Margin collapsing
  • Sizing
    • content-box vs. border-box
    • width, height, min/max constraints and overflow
  • Display and Spacing
    • block, inline, inline-block and none
    • Borders, shadows and consistent spacing

Example Code

.demo-box {
  width: 220px;
  padding: 20px;
  border: 4px solid #1f7061;
  margin: 16px auto;
  background: #eef6f3;
}

Output

Content, padding, border and margin
