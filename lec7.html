Lecture 7

CSS Positioning and Stacking

Placing elements exactly where you want them

Summary

This lecture starts from normal document flow and then shows how relative, absolute, fixed and sticky positioning move elements. It explains the containing block, the order in which overlapping elements stack, and common float problems.

Topics Covered

  • Document Flow
    • Normal flow and static positioning
  • Positioning
    • relative, absolute, fixed and sticky
    • Offset properties and the containing block
  • Stacking and Floats
    • z-index and stacking contexts
    • Floats, clearing and layout pitfalls

Example Code

.pos-parent {
  position: relative;
  height: 110px;
}
.pos-badge {
  position: absolute;
  top: 10px;
  right: 10px;
}
