Lecture 1

Introduction to Web Development

How the web works and the words everyone uses for it

Summary

This lecture introduces the course and explains the difference between the Internet and the Web. It describes the client-server request-response model, the core terminology of the web, the standards bodies behind it and the main types of web applications.

Topics Covered

  • Course Introduction
    • Course learning outcomes
    • Assessment plan and grading policy
  • Internet and Web
    • Internet vs. Web
    • Client-server request-response model
    • URL/URI, HTTP/HTTPS, DNS, hosting, web server and browser
  • Standards and Application Types
    • W3C, WHATWG, ECMA and IETF
    • Static, dynamic, MPA, SPA and PWA
