Lecture 5

Cascading Style Sheets (CSS) Fundamentals

Choosing what to style and how

Summary

This lecture introduces CSS syntax and the three ways of adding styles. It covers the main selectors, pseudo-classes, the rules the browser uses to resolve conflicts, and the properties for colour, fonts, text and backgrounds.

Topics Covered

  • Adding CSS
    • CSS syntax
    • Inline, internal and external style sheets
  • Selectors
    • Element, class, id, attribute, grouping and descendant
    • Pseudo-classes and pseudo-elements
  • Cascade and Properties
    • Cascade, specificity and inheritance
    • Colour, font, text and background properties

Example Code

#demo-title { color: #1f7061; }
.demo-list .done { color: #134b40; font-weight: 700; }
.demo-list li:hover { background: #d9efe6; }
